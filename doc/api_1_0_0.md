# Public API for 1.0.0

Sleuth 1.0.0 has two public libraries:

- `package:sleuth/sleuth.dart` is the main API. Breaking changes to it need a major release.
- `package:sleuth/validation.dart` holds the capture and validation tooling used by the example app's capture screens and by the evidence audits. It is outside the semver promise and can change in a minor release.

Members marked `@visibleForTesting` or `@experimental` are outside the promise too. So are members of main-API classes whose types come from `validation.dart`; their dartdoc says so.

Every `export` line in both libraries has a `show` list. `test/validation/public_api_test.dart` compares the exported names with a committed list.

## Moved to `package:sleuth/validation.dart`

Each of these is marked `@experimental`, as are the `validationMetadata` getters of the main-API detectors. The CI API diff leaves `validation.dart` out. It rates a change to an `@experimental` declaration, or to a member of one, as minor. Removing an `@experimental` member of a class that is not experimental, such as a capture static on `Sleuth`, counts as breaking. The diff fails only on a breaking change without a major version bump.

## Member changes

- **`Sleuth` capture statics get `@experimental`.** `markScenarioBegin`, `markScenarioEnd`, `flushTimelineNow`, `exportCaptureJson`, `lastCaptureExportFailure`, `diagnoseCaptureState`, `suspendNonEssentialTimelineStreams`, `resumeAllTimelineStreams`, `holdAllocationProfileReads`, `releaseAllocationProfileReads`, `setHeapGrowingLegsForCapture`, `pollStreamResourceAllocationProfileNow`, `lastPollTimings`, and the accessors typed with `validation.dart` types: `repaintDetector`, `memoryPressureDetector`, `startupDetector`, `trackedResourceDetector`.
- **`Sleuth` test statics keep `@visibleForTesting`.** `startupClockForTest`, `resetStartupForTest`, `setStartupMetricsForTest`.
- **Three package-internal `Sleuth` statics move to `lib/src`.** `enrichStartupWithVmData` (called by the controller), `dartEntryMonotonicUs` (read by two detectors) and `notifyControllerDisposed` (called by the overlay) were public only because `Sleuth` is, and the analyzer rejects `@internal` in `lib/sleuth.dart`.
- **`RouteSession`.** `endedAt` and `scanCycleCount` become read-only getters. Route health output does not change.
- **`SleuthThemeData` loses the fields the overlay no longer reads.** They go from the constructor, the presets, `copyWith`, `fromColorScheme` and the contrast table:
  - `confidenceConfirmed`, `confidenceLikely`, `confidencePossible` and `confidenceColor`;
  - `effortQuick`, `effortMedium`, `effortInvolved` and `effortColor`;
  - `sourceVmTimeline`, `sourceDebugCallback`, `sourceStructural`, `sourceNone`, `sourceAccentWidth` and `sourceAccentColor`;
  - `badgeVmBg`, `badgeVmText`, `badgeFrameBg`, `badgeFrameText`;
  - `bannerInstrumentationBg`, `bannerInstrumentationText`;
  - `aiShimmerStart`, `aiShimmerMid`, `aiShimmerEnd`;
  - `aboutBackground`, `cardJankFlash`, `effectsBadge`, `fixHintText`, `disclaimerText`, `highlightLabelText`;
  - `fontXxl`, `fontDisplay`, `focusRingWidth`.
- **`WidgetHighlight.stableId` (new).** The stable id of the issue a highlight belongs to, for issues that list several widgets. The crosshair on such a card steps through their outlines.
- **Enums that may grow.** The dartdoc of `DetectorType`, `IssueCategory`, `ObservationSource`, `PipelinePhase`, `InteractionContext` and `FixEffort` says a minor release can add values, so a `switch` over them needs a default branch.
- **`FixEffort` dartdoc** names `FixHintBuilder` in plain text instead of a link.

## Kept on purpose

- `SleuthConfig.frameTimingWarmupFrameCount` still works (default 0).
- The `vm_service` types in `ParsedTimelineData` stay. Wrapping them would copy every timeline event on its way to the detectors. A `vm_service` major release means a Sleuth major release.
