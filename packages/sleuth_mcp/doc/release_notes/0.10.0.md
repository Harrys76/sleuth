# sleuth_mcp 0.10.0 release notes

The full list of changes in sleuth_mcp 0.10.0. [CHANGELOG.md](../../CHANGELOG.md) has the summary.

Pins sleuth 1.0.0 and accepts the 0.38 lineage as the prior fallback, so the sidecar now refuses 0.37 apps (`version_skew_major`). Publish it together with sleuth 1.0.0, because sidecar 0.9.0 refuses 1.0.0 apps.

- **Lineage by major from 1.0.0.** sleuth 1.x follows semver, so a breaking change takes a major release. `versionLineage` returns the major for versions from 1.0.0 up (`1.4.2` gives `1`) and `major.minor` below it (`0.38.1` gives `0.38`). Any 1.x app connects, with `warning: version_skew_minor` when it is not the pinned version. The sidecar refuses a 2.x app and anything that is not `major.minor.patch`.
- **Version warning in `compare_snapshots`.** One lineage now spans every 1.x release, so `compare_snapshots` diffs a 1.0.0 snapshot against a 1.2.0 one. The result then carries `versionWarning`, which starts with `sleuth_version_differs:` and names both versions. A release can add detectors, move thresholds or fix false positives, so part of the diff may come from the upgrade rather than the app. Build metadata (`+...`) does not count as a different release. Snapshots from different lineages are still refused with `arg_lineage_mismatch`.
- **`measurement` in compact issues.** `get_issues` and `get_snapshot` keep each issue's `measurement` object in their default compact shape: `value`, `unit`, `warningAt`, `criticalAt`, `windowMs`, `warningStrict` and `criticalStrict`. Issues without a number leave it out.
- **Not useful marks.** The app lists the issues marked Not useful in the overlay under `notUsefulMarks`, in both `ext.sleuth.issues` and `ext.sleuth.snapshot`. `get_issues` passes the key through, and the sidecar's snapshot projection keeps it like `suppressedCount`.
- **Docs.** The schema copy documents `notUsefulMarks` and the `measurement` shape; the tool schema lists `measurement` among the compact keys, documents `versionWarning`, and describes `arg_lineage_mismatch` with lineages by major from 1.0.0.
